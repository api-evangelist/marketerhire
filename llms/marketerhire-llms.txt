## What MarketerHire is

MarketerHire sells access to human marketing talent, not software. Clients describe a need, are
matched with a vetted marketer in 24-48 hours, and work month-to-month with a two-week refundable
trial. Roles covered include growth marketing, paid media/performance, SEO and content strategy,
email and lifecycle, brand and creative, marketing operations, and fractional CMO engagements.

## API surface

**MarketerHire publishes no public API.** As of 2026-08-25 there is no developer portal, no API
reference, no OpenAPI/AsyncAPI/GraphQL/gRPC/WSDL contract, no MCP server, no A2A agent card, and no
client SDK in any public package registry. Probes of `/openapi.json`, `/openapi.yaml`,
`/swagger.json`, `/v1/openapi.json`, `/api-docs`, `/docs`, `/redoc` and `/graphql` on
marketerhire.com all returned HTTP 404; the same paths on app.marketerhire.com return HTTP 500 from
a generic error handler. `api.marketerhire.com`, `docs.marketerhire.com`,
`developers.marketerhire.com` and `status.marketerhire.com` resolve only through a wildcard
Vercel DNS record and present no valid TLS certificate — they are not served.

The one first-party HTTP service whose source is public is **BrightMatter**, in
https://github.com/MarketerHire/mh-brain — a FastAPI application (`api.py`) exposing roughly 22
routes under `/api/v1/` (health, episodes, guidance, outcomes, tracking, consolidation, patterns,
knowledge-centre and dashboard reads), authenticated by an `X-API-Key` header and deployed to Modal
(`modal_app.py`). Its own documentation only ever names `http://localhost:8100`; no production base
URL is published, so it is not a callable public API and no contract has been derived from it.

## Agent guidance

There is nothing here for an agent to call. Do not construct requests against
`api.marketerhire.com` or any `*.marketerhire.com` host — the wildcard DNS record makes unserved
names resolve, and `talent.marketerhire.com` returns HTTP 200 for paths that do not exist. To
engage MarketerHire, use the human intake form at https://marketerhire.com/hire.
